Open teaching materials

Three labs from GRG 356T, each a single Jupyter notebook with its data. They run in Google Colab or a local Python environment; each opens with a setup cell that installs what it needs.

Licence: text and notebooks under CC BY 4.0, code under the MIT licence. Some datasets carry their own terms; see About & licence.

Lab 3: Geocoding and web scraping

Students send web requests, geocode addresses, collect Street View images and scrape rental listings, then ask what the scraped data leaves out: which housing, which neighbourhoods and which renters never appear.

You will need your own Google Maps Platform API key (Geocoding API and Street View Static API). The rental-listing pages used in class are not redistributed, because they belong to the listing site; the notebook scrapes the live pages.

Lab 8: Network analysis and access to maternal care

Street-network centrality with OSMnx, then the two-step floating catchment area (2SFCA) method to measure access to obstetric beds across Texas's 254 counties, and three measures of how unequal that access is: the Index of Dissimilarity, the Gini coefficient and the Atkinson index. The travel-time threshold is the students' choice, and the lab asks how much that choice changes who looks under-served.

Data: county totals of births and obstetric beds, aggregated from a Texas maternal-health dataset provided by Ji Sun Lee (individual records are not shared); county-to-county drive times from OpenStreetMap via OSRM; Census county boundaries.

Lab 8 on GitHub

Lab 10: Generative AI in geography and cartography

Part A follows CartoAgent: a multimodal model turns a picture into a web-map style, then judges its own map. Part B asks two models which Texas counties border each county and scores every answer against official Census adjacency data, to test whether the models know small, rural counties as well as large ones, and whether a better prompt helps beyond ordinary run-to-run variation.

You will need an OpenAI API key. A full run costs about $1.20. A free Mapbox account is used for Part A.
