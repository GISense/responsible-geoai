# Responsible GeoAI for Civic Futures

Website and open teaching materials for **GRG 356T Spatial Data Science and Maps**,
Department of Geography and the Environment, The University of Texas at Austin.
Supported by the Mozilla Foundation.

- Website: https://gisense.github.io/responsible-geoai/
- Open labs: [`labs/lab03`](labs/lab03) (geocoding and web scraping),
  [`labs/lab08`](labs/lab08) (network analysis and access to maternal care),
  [`labs/lab10`](labs/lab10) (generative AI in geography and cartography)

Each lab is one Jupyter notebook with its data. Open it in Google Colab or a local
Python 3.11 environment and run the setup cell first.
